MrfAutomation

Project Overview

MRFAutomation is a web-based test automation framework designed to automate key functionalities of a application. The framework uses Selenium WebDriver, Java, TestNG, and the Page Object Model (POM) to create maintainable and reusable automated test scripts.

Technologies Used

Programming Language: Java

Automation Tool: Selenium WebDriver

Testing Framework: TestNG

Design Pattern: Page Object Model (POM)

Build Tool: Maven

Reporting: Extent Reports

Version Control: Git and GitHub

CI/CD: Jenkins

IDE: Eclipse
